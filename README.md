# BF3Antihook

BF3 AntiHook-AntiCheats

## Herramienta Rust en PHP 7

El módulo independiente [`rust-server-helper`](rust-server-helper/README.md) prepara el comando `client.connect IP:PUERTO` para servidores Rust locales o públicos. No intenta modificar la pestaña **Official Servers**, porque esa lista es administrada por Facepunch y no puede alterarse desde un proyecto externo.

Para ejecutarlo:

```bash
cd rust-server-helper
php -S 127.0.0.1:8080 -t public
```
